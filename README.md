# Library Management System

A simple library management application developed with PHP, MySQL, HTML and CSS.

## Features

- Add and manage books
- Organize books by category
- Register friends or borrowers
- Record book loans
- Track loan history

## Technologies

- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Local Setup

1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Create a MySQL database named `my_library`.
4. Create the required tables.
5. Configure the database connection in `includes/db.php`.
6. Start MySQL and run the application locally.

## Project Status

This project is a learning project built to practise PHP development and database management.
